初始化接入流程

在不同操作系统下接入两元店订阅服务，均需完成以下三个标准配置步骤。

STEP 01

获取订阅链接

在控制中心生成专属于当前账户的订阅令牌。妥善保存该 URI 字符串，切勿公开发布，以免造成配额被第三方盗用。

STEP 02

写入客户端配置

在对应的客户端软件中新建订阅源，填入订阅 URL。建议将自动更新时间间隔设为 720 分钟（12小时），以便及时同步节点变动。

STEP 03

选择策略并建立分流

在路由规则中选择“按规则分流”（Rule 模式），根据实际延时选择可用节点组，启动系统代理或 TUN 虚拟网卡模式。

各平台客户端指引

两元店不提供捆绑特定修改的核心文件，建议选用行业标准的通用客户端进行接入。

Windows

建议使用 Clash Verge Rev、Clash Nyanpasu 或 v2rayN。支持通过系统托盘快速切换代理规则，推荐启用 TUN 模式以接管全局应用流量。

macOS

兼容 Clash Verge Rev (macOS 版)、Surge 或 Sing-box 原生 GUI。需要授予系统网络扩展权限以支持系统分流与 DNS 劫持防护。

Android

推荐使用 Clash Meta for Android 或 v2rayNG。系统需开启“允许客户端创建 VPN 连接”，并在电池策略中设为“无限制”以防后台中断。

iOS / iPadOS

支持 Shadowrocket、Stash 或 Loon 等已在 App Store 上架的工具软件。通过扫码或粘贴 URL 完成节点配置导入并激活 VPN 描述文件。

技术支持与常见问题

针对连接阻断、策略异常以及账户配额的标准化排查建议。

订阅更新提示校验失败或空节点列表如何解决？

首先确认当前网络未对订阅托管域名的 DNS 解析进行污染。可临时使用手机移动网络热点尝试拉取；若仍失败，检查客户端是否启用了“跳过证书验证”或更新至最新内核版本。

多台设备连接时是否会互相踢出？

两元店系统依据实时在线连接的公网 IP 数量与活跃 Session 进行判定。只要并发在线设备数未超出所订购套餐上限，各设备可并行业务，无需手动注销其他终端。

系统时间偏差对 TLS 握手有何影响？

主流加密代理协议对本地系统时间精度有极高要求。若本地时钟与标准网络时间（NTP）偏差超过 90 秒，TLS 握手将直接被服务端拒签并报握手超时错误。请校准本地时间。

当月流量消耗完毕后服务如何运作？

流量耗尽后，节点分发控制面板将自动切断当前订阅的代理转发链路，直到下一个自然计费周期开始重置，或由用户在后台执行手动增购/提前续费操作。
